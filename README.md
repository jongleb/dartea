# dartea

An independent compiler for the Elm language, written in OCaml, emitting modern
JavaScript. dartea is not affiliated with or endorsed by the Elm project.

It does contain material derived from elm/core, elm/virtual-dom, elm/html,
elm/browser, elm/json and elm/compiler, all copyright Evan Czaplicki under BSD 3-Clause. See
[LICENSE](LICENSE) for the file-by-file breakdown and the license text.

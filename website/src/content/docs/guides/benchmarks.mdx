## Result

[js-framework-benchmark](https://github.com/krausest/js-framework-benchmark) is the standard way to compare how fast frameworks create, update, swap and remove rows of a table. The score is the weighted geometric mean of slowdowns against hand written vanilla JavaScript. Lower is better.

The dartea program is the official Elm implementation from the benchmark repository, with `Array` and `Random` replaced by `List` and a small generator, because dartea does not have those modules yet. Same model, same messages, same `view`. The difference to Elm 0.19.1 comes from the compiler and the runtime.

## Run it yourself

The script uses a dartea built from source, so you need OCaml 5.4 with `dune` first.

```sh
git clone https://github.com/jongleb/dartea
cd dartea
opam install . --deps-only
dune build
sh bench/run.sh
```

The script clones js-framework-benchmark into `_bench`, adds dartea as one more keyed framework, builds the official vanilla, Elm, React, Svelte and Solid implementations and runs the official runner headless. Every measurement is the median of 15 runs, from the click to the end of the last paint in a Chrome trace. The result page is at `_bench/webdriver-ts-results/dist/index.html`.
